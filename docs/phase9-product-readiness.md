# Phase 9: design polish and product readiness

Phase 9 makes windowsRICE closer to a product people can install and rely on:
- per-module appearance that reaches the running bar;
- restrained, switchable motion;
- Studio refinements;
- high-contrast colours in the Studio;
- measured performance;
- a tested installer.

Decisions are in `docs/adr/ADR-0006-packaging-and-motion.md`. Evidence labels follow `docs/development.md`.

Test machine: Windows 11 Pro 25H2 build 26200, Ryzen 9 5900X (24 logical CPUs), Radeon RX 9070 XT, one MSI MAG323UPF at 3840×2160 and 150%. All runs used isolated configurations, fixed window titles and pinned test backdrops. The owner's configuration, registry and Start menu were not changed.

## 1. Starting point (audit)

- **Git:** branch `master`, HEAD `20981ec`, Phases 3.5 to 8 uncommitted (32 paths).
- **Already present:**
  - theme duplicate, edit, rename (name field), save and delete with confirmation;
  - complete preset management (save, load, duplicate, rename, delete, validated import, export, no silent overwrite, format v2 reading v1);
  - compositor fades for showing the bar and the popup, respecting Windows "Animation effects";
  - keyboard navigation and UI Automation in bar, popup and Studio;
  - high contrast in the bar.
- **Missing or incomplete:**
  - per-module appearance (only label, width, 12-hour clock);
  - a way to turn motion off in windowsRICE itself;
  - any motion when applying a design or scrolling;
  - a high-contrast Studio (it used theme colours);
  - fixed-width and Korean font filters;
  - a right-end preview close-up that cut modules in half;
  - font discovery on the UI thread (measured up to 1.5 s once in a fresh process);
  - any packaging: no icon, no version information, no installer, no way to close a running bar from a script.

## 2. What was built

**Per-module appearance.** New optional `[[bar.modules]]` fields:
- `content`: what the module shows (icon only, value only, icon and value, everything);
- `color`: accent of the module's icon and value;
- `background`: a tile in the module's own colour;
- `font_size`: 10–20;
- `density`: compact, normal or expanded;
- `value_format`: RAM and VRAM as a percentage or the amount in use (`12.5 GB`);
- `speed_unit`: upload and download in bytes or bits (`20.0 Mb/s`);
- `show_date`: clock with or without the date.

The bar style applies when a field is unset. Fields are validated per kind (for example `speed_unit` only on upload and download). Module colours are checked for 4.5:1 against their tile or the bar surface. Unavailable readings stay "—", also in amount format; nothing is invented.

In the Studio, select a module card in Modules; the "Appearance of …" editor below has content choices, accent and background swatches, text size, density, the kind-specific options and "Use the bar style". The preview, the running bar, presets and restored configurations all use the same `build_bar` path.

**Motion.**
- **Apply transition:** the bar fades the new design in from 35% opacity (at most 200 ms), on DirectComposition, without redrawing.
- **Smooth scrolling:** the Studio eases towards the target on a 15 ms timer that stops when it arrives.
- **Off switch:** Advanced › Motion › "Animations" turns every fade and the smooth scrolling off (`[bar] animations = false`). Windows' "Animation effects" setting is respected as before. Nothing animates while idle.

**Studio refinements.**
- Font gallery filters: all fonts, Korean supported, fixed width (detected through DirectWrite).
- The right-end close-up in the preview starts at the first whole module.
- Groups whose members have all scrolled out of view are left out of the accessibility tree.
- High-contrast mode gives the Studio the system colours.
- "New theme from this design" creates a validated custom theme from the current design's colours and switches to it.
- The weight count reads "1 weight".
- Fonts are discovered once per process on a background thread and cached; Studio openings show 0 ms for fonts.

**Packaging.**
- **Resources:** `apps/panel/build.rs` compiles the icon (`assets/windowsrice.ico`, generated by `scripts/make-icon.ps1`) and version information into the exe with the Windows SDK `rc.exe`. Without it, the build continues with a warning. Windows now shows the icon on the exe and on the Studio's title bar.
- **`--quit`** asks a running bar to exit cleanly (it releases its reserved strip).
- **`packaging/install.ps1`**, per user and without administrator rights:
  - installs into `%LOCALAPPDATA%\Programs\windowsRICE`;
  - adds Start menu shortcuts (windowsRICE, and windowsRICE Design Studio);
  - adds an Apps & features entry (current user);
  - adds a Startup shortcut only with `-StartWithWindows` (an upgrade keeps the choice);
  - closes a running bar with `--quit`, then swaps the folder with a rename;
  - never touches `%APPDATA%\windowsRICE`.
- **`packaging/uninstall.ps1`** removes everything it installed and keeps settings unless `-RemoveSettings` is given.
- **`scripts/package.ps1`** builds `target\dist\windowsRICE-<version>-win-x64.zip` and a SHA-256 file.

## 3. Packaging instructions

```
powershell -ExecutionPolicy Bypass -File scripts\package.ps1          # build and zip
powershell -ExecutionPolicy Bypass -File scripts\package-verify.ps1   # sandbox test
```

Output: `target\dist\windowsRICE-0.1.0-win-x64.zip` (1,130 KB) and `.sha256`. To install, extract the zip and run `install.ps1` (see `packaging/INSTALL.txt`).

Signing is not done. It needs a code-signing certificate, `signtool` from the Windows SDK, and a timestamp server; until then SmartScreen warns on first run. Nothing was published or uploaded.

## 5. Performance (real, release, `scripts/perf-quick.ps1`)

| Measurement | Result |
|---|---|
| Startup to first frame (3 runs) | 190, 195, 202 ms (an earlier cold run: 543 ms) |
| Idle CPU (60 s) | 0.42% of one core (0.017% of the machine) |
| Idle redraws | 54 per minute (readings that changed) |
| Frame cost (median) | draw 0.74 ms, present 0.20 ms |
| Bar memory | private 46.8 MiB, working set 57.6 MiB, GPU dedicated 19.1 MiB, 1,250 handles |
| Studio open | private 83.2 MiB, GPU 56.2 MiB |
| Studio after scrolling the font gallery | private 87.7 MiB, GPU 59.7 MiB |
| After closing the Studio | private 71.2 MiB, GPU 18.4 MiB, 1,310 handles |
| After a second open and close | private 71.7 MiB, GPU 18.6 MiB, 1,308 handles |
| Studio scene build | median 1.76 ms, maximum 6 ms (359 builds) |
| Font discovery at Studio opening | 0 ms (cached; background thread at startup) |

**Cleanup.** Closing the Studio releases its GPU memory and handles. About 24 MiB of private memory stays after the first close and does not grow on the second, so it is a bounded cache (DirectWrite font faces and interned family names), not a leak.

## 6. Accessibility and Windows integration

- **Verified automatically:**
  - UI Automation trees of bar, popup and Studio;
  - keyboard navigation (grids, sliders, text editing);
  - focus visibility in the scene model;
  - Korean and English labels;
  - an accessibility lint at every Studio size, language and scroll position.
- **Implemented, not verified on screen:**
  - the high-contrast Studio (turning high contrast on changes a system setting);
  - fades disabled under "Animation effects off" (the switch is read from Windows; not toggled here).
- **NOT VERIFIED (manual or hardware):**
  - Narrator;
  - real high-contrast mode;
  - real DPI changes and mixed DPI;
  - multiple monitors and hot-plugging;
  - the stable monitor id (see §4);
  - typing Korean with the IME by hand;
  - clipboard shortcuts in the running window;
  - running the real installer into the owner's profile (only the sandbox was tested, without registry writes).

### Manual verification steps

1. **Narrator:** start Narrator (Ctrl+Win+Enter) and open the Studio from the bar's menu.
   - Tab through the header and sections, then use the arrow keys in a gallery. Each card should be announced with name, description and selection.
   - In Modules › Appearance, change the text size and hear the new value.
2. **High contrast:** Settings › Accessibility › Contrast themes, choose one. The bar and the Studio should use the system colours. Choose None to return.
3. **Animation effects:** Settings › Accessibility › Visual effects › Animation effects off. Opening the menu and applying a design should not fade.
4. **DPI:** change Settings › Display › Scale while the Studio is open. The text should stay sharp and the layout fit; then return to 150%.
5. **Multiple monitors:** connect a second display. A second bar should appear. In Studio › Advanced, turn it off and Apply. Disconnect it; the bar should be removed cleanly.
6. **Installer (real):** extract the zip, run `install.ps1 -Launch`.
   - The Start menu should list windowsRICE, and Settings › Apps should list it.
   - Uninstall from Settings › Apps; `%APPDATA%\windowsRICE` should remain.

## 7. Limitations and deferred items

- **No signed installer and no MSI or MSIX.** No certificate or installer toolkit is available.
- **No blur behind the bar** (ADR-0005).
- **Hover and selection feedback are not animated.** That would need continuous Studio redraws.
- **New fonts** installed while windowsRICE runs appear in the Studio after a restart.
- **Per-module typography** covers size only; the family and weight follow the bar.
- **Per-module icon style** is the accent colour; the icon font follows the bar's icon set.
- **The monitor test** no longer requires a device path (§4).
